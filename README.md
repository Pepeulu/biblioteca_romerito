
# Instalacão dos frameworks e outras dependências

1. Baixe o node e o next js

```bash
npm install
```

2. Inicie o servidor:

```bash
npm run dev
```

ou

```bash
npm run build
```

```bash
npm start
```

3. Acesse em <http://localhost:3000>

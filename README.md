
# Instalacao

Baixe o node e o next js

Instale as dependencias:

```bash
npm install
```

Inicie o servidor:

```bash
npm run dev
```

ou

```bash
npm run build
```

```bash
npm start
```

Acesse em <http://localhost:3000>
